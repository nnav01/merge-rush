Merge Rush is a browser puzzle game built on Squeekchain's Squeek economy. Each run lasts 24 rounds of 10 minutes of hamster wheel time. Players merge two Squeeks of the same level into one of the next level, using the merge rules from the Squeekchain whitepaper (levels 1 to 10, power x2.2 per level, +10% when merging, cooldown after a merge). They can deposit Squeeks into a 4-slot staking vault that pays SQK each round based on Squeek power, in the spirit of Proof of Squeek. Each round is driven by Squeektoshi's wheel: a nap, a jog or the zoomies decides how many new Squeeks arrive and whether cooldowns clear. A daily challenge uses one shared wheel sequence for all players (UTC), so scores can be compared and shared. It runs fully in the browser and does not move any tokens.
